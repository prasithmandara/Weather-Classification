# Weather-Classification
A machine learning project that classifies weather conditions using the K-Nearest Neighbor (KNN) algorithm, implemented in a Jupyter Notebook

What it does:
  This project uses historical weather data and feature measurements to predict / classify weather types such as:

  Sunny 
  Rainy 
  Cloudy 
  Snowy

Tech Stack: Python / Jupyter Notebook / scikit-learn / pandas / numpy / (matplotlib / seaborn)
Purpose: Programming language / Interactive development environment / KNN algorithm implementation / Data loading and manipulation / Numerical computation / Data visualization

Algorithm:

K-Nearest Neighbors (KNN) classifies a data point by looking at the k closest training examples and assigning the most common label among them.
Key steps:

Load and explore the weather dataset
Preprocess and normalize features
Split data into training and test sets
Train the KNN classifier
Evaluate model performance
Visualize classification results

What I learned:
  Applying KNN to a real-world weather classification problem
  How feature scaling affects KNN performance (since KNN is distance-based)
  How to evaluate a classifier using accuracy score and confusion matrix
  Exploring the effect of different k values on prediction accuracy
  How to visualize multi class classification results
